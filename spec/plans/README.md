# Plans

One detailed plan file per milestone, written **before** building that milestone.

## Naming
`milestone-1.md`, `milestone-2.md`, ... — one file per milestone in `MILESTONES.md`.

## What a plan file contains
- Which files to create or change
- The structure / approach for this milestone
- Anything the build should follow

## Note
A plan bridges planning → building for one milestone. After the milestone is built, the **code** and `MILESTONES.md` are the source of truth — old plan files are kept only as an archive.
