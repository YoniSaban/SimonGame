# תוכנית – Milestone 7: גרסה סופית ב-GitHub Pages ובדיקת מכשיר

## מטרה
לוודא שהגרסה המלאה (Milestones 1–6) מפורסמת אוטומטית ב-`https://yonisaban.github.io/SimonGame/` דרך HTTPS, ניתנת להתקנה ועובדת Offline בטלפון אמיתי, ושעדכון גרסה אינו מפריע למשחק פעיל. זו אבן דרך של **אימות ותיקון פערים** – אין יכולות חדשות.

## מצב נוכחי (נבדק בעת התכנון)
- `.github/workflows/deploy.yml` קיים: `npm ci` → typecheck → test → build → `upload-pages-artifact` → `deploy-pages`, הרשאות מינימליות, Node מ-`.nvmrc`, `concurrency` ללא ביטול באמצע.
- האתר החי מחזיר 200; `manifest.webmanifest` ו-`sw.js` נגישים תחת `/SimonGame/`.
- `vite.config.ts`: `base` ו-`start_url`/`scope` מאותו קבוע, `registerType: 'prompt'`, ללא `skipWaiting`/`clientsClaim`.
- `gh` CLI אינו מותקן – מצב ה-Workflow ייבדק דרך ה-API הציבורי של GitHub (`curl https://api.github.com/repos/YoniSaban/SimonGame/actions/runs`) או דרך הדפדפן.

## קבצים
- **לא צפויים שינויי קוד.** שינוי יתבצע רק אם תתגלה תקלה בבדיקות; כל תיקון כזה יתועד, ואם הוא משמעותי – כ-ADR.
- `spec/MILESTONES.md` – סימון 🟡 בסיום הבנייה.
- `CLAUDE.md` – עדכון סעיף Run commands רק אם משהו השתנה.

## שלבי הבנייה

### 1. בדיקת ה-Workflow
- סקירת `deploy.yml` מול סעיף 2.9 ב-`ARCHITECTURE.md`: טריגר `push` ל-`main`, סדר השלבים, הרשאות, Node נעול, Build שנכשל לא נפרס.
- בדיקה שגרסאות ה-Actions (`checkout`, `setup-node`, `upload-pages-artifact`, `deploy-pages`) קיימות ותקינות.
- בדיקת היסטוריית הריצות דרך ה-API: הריצה האחרונה (Milestone 6) הצליחה, ופורסמה ללא פריסה ידנית.

### 2. בדיקה מקומית מלאה על Build
- `npm ci`, `npm run typecheck`, `npm run test`, `npm run build` – הכל עובר.
- `npm run preview` → `http://localhost:4173/SimonGame/` בדפדפן המובנה, באמולציית טלפון אנכי (360px ו-375px):
  - עברית/RTL, ללא גלילה אופקית.
  - משחק מלא: הפסד בשלב 1, הפסד בשלב מתקדם, ניצחון אחרי 10 שלבים (בעזרת סקריפט בדיקה שמקיש את הרצף), קונפטי בניצחון בלבד.
  - השהיה במעבר ל"אודות" וחידוש עם "המשך משחק".
  - שמירת עשר תוצאות לכל היותר, ומחיקה מאושרת (ביטול / מחק).
  - Manifest ו-Service Worker תקינים, Precache הושלם, אין שגיאות 404 בקונסול וברשת.
  - Offline: ניתוק רשת (דרך Service Worker/מצב Offline בכלים) → טעינה מחדש, משחק, ניווט והיסטוריה עובדים.
- כיבוי ה-preview בסיום.

### 3. בדיקת האתר החי (לפני Push – על הגרסה של Milestone 6)
- `https://yonisaban.github.io/SimonGame/` נטען דרך HTTPS כמשחק עובד (לא דף לבן).
- כל המשאבים (JS, CSS, פונט, אייקונים, Manifest, `sw.js`) נטענים תחת `/SimonGame/` ללא 404.
- ה-Service Worker נרשם, וה-Manifest כולל שם, אייקונים, `start_url`/`scope` נכונים – תנאי ההתקנה מתקיימים.

### 4. בדיקת "עדכון גרסה אינו מפסיק משחק"
- בדיקה אוטומטית קיימת (`src/pwa/update.test.tsx`) מאמתת שהפס מוצג רק ב-`idle` – לוודא שהיא עוברת.
- בדיקה מקומית אמיתית: `preview` של ה-Build הנוכחי, התחלת משחק; ואז Build שני עם שינוי זמני וזעיר (שמבוטל מיד אחרי הבדיקה) כדי ליצור גרסה חדשה. תוצאה צפויה: בזמן משחק – אין פס עדכון ואין רענון; אחרי סיום וחזרה ל-`idle` – הפס "יש גרסה חדשה" מופיע, ו"עדכן" טוען את הגרסה החדשה.
- הערה: Push שמשנה רק את קובצי ה-`spec/` אינו יוצר גרסה חדשה של האפליקציה, ולכן בדיקת העדכון בטלפון תתאפשר רק בפריסה הבאה שמשנה קוד.

### 5. הוראות בדיקה לטלפון (למשתמש)
הכנת רשימה פשוטה בעברית, שלב אחר שלב, ל-iPhone (Safari) ול-Android (Chrome):
1. פתיחת הכתובת, משחק אחד מלא.
2. התקנה: iPhone – כפתור שיתוף → "הוסף למסך הבית"; Android – תפריט ⋮ → "התקן אפליקציה".
3. פתיחה מהאייקון, ואז מצב טיסה → סגירה ופתיחה מחדש → משחק, צלילים, ניווט, היסטוריה.
4. צלילים עם מתג שקט פתוח וסגור (ב-iPhone).
5. נעילת מסך באמצע רצף → פתיחה → "המשך משחק" מציג את הרצף מההתחלה.
6. מעבר לאפליקציה אחרת באמצע משחק וחזרה – אותו כלל.
7. (רשות, רק אם ה-Push משנה קוד) עדכון גרסה: משחק פעיל לא מתרענן; הפס "יש גרסה חדשה" מופיע רק כשאין משחק.

### 6. סיום הבנייה
- בדיקת כל סעיפי ה-Definition of Done ודיווח: מה נבדק על ידי (עבר/נכשל) ומה ממתין לבדיקת המשתמש בטלפון (התקנה, Offline במכשיר, מצב שקט, נעילת מסך) – בלי להציג בדיקה שלא בוצעה כאילו עברה.
- סימון 🟡 ב-`MILESTONES.md`. ללא Commit.

## אחרי אישור המשתמש (Push)
- Commit + Push ל-`main` → מעקב אחרי ה-Workflow דרך ה-API עד הצלחה.
- בדיקת האתר החי אחרי הפריסה (נטען, ללא 404, Service Worker פעיל, הגרסה החדשה).
- דיווח למשתמש. זו אבן הדרך האחרונה – אחרי אישורה כל יכולות ה-PRD מכוסות.
